# Vanguard Skin — Session Start Checklist

The checklist is agent-neutral and maintained in ONE place: read `.claude/session-start.md` (repo root) and follow it exactly. It gathers repo state, cross-agent inboxes (GitHub issues are the Codex outbox; `docs/HANDOFF.md` is the Claude session handoff), and the TODO backlog, then presents a ranked session-focus menu for the user to pick from.

Do not duplicate the steps here — the `.claude/session-start.md` file is the single source of truth for both agents.
